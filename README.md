# Knowledge Distillation from GPT to Qwen for Arabic Handwritten Text Recognition

**MAI 656 — Natural Language Processing | Canadian University Dubai | Spring 2026**

---

## Overview

This project implements a knowledge distillation pipeline that transfers Arabic handwritten text recognition (HTR) capabilities from a large commercial vision-language model (GPT) to a compact, self-hosted open-source model (Qwen2.5-VL-7B-Instruct) using Low-Rank Adaptation (LoRA) fine-tuning.

The core idea: use GPT as a "teacher" to label handwritten Arabic images, then fine-tune a smaller "student" model to replicate that capability — locally, at near-zero inference cost, with full data privacy.

---

## Pipeline
AHTD Images → GPT Labeling → Format Conversion → LoRA Fine-Tuning → Evaluation
↓
Downstream NLP (NER + POS)
Baseline Comparison (EasyOCR)

---

## Dataset

- **Source:** Arabic Handwritten Text Dataset (AHTD) — paragraph-level handwriting images
- **Size:** 1,400 images labeled by GPT (`gpt-5.4-mini`)
- **Split:** 1,120 train / 280 eval (80/20, `random.seed(42)`)
- **Format:** Qwen2.5-VL conversational JSONL with base64-encoded images

---

## Results

| Model | CER | Notes |
|---|---|---|
| EasyOCR Arabic (zero-shot) | 0.48 | Single-purpose Arabic OCR; fastest; no structured output |
| Qwen2.5-VL + LoRA (long refs) | 0.83 | General-purpose VLM; structured JSON; improvable with more data |
| Qwen2.5-VL + LoRA (all refs) | 1.28 | Inflated by short-reference insertions (2.9% of eval set) |

**Downstream NLP (on 280 GPT transcriptions):**
- NER: Precision 0.51 / Recall 0.68 / F1 0.58 (Qwen vs GPT reference)
- POS tagging: 87.53% tag-level accuracy

Clearly, EasyOCR wins on raw CER at this training scale, Qwen offers more in exchange for that gap, and the gap is expected to narrow as training data grows.

## Key Findings

- A 7B-parameter VLM fine-tuned on 1,120 samples in 44 minutes achieves 0.829 CER on paragraph-length Arabic handwriting — at roughly 1/10th the per-image cost of the GPT API.
- OCR errors at 5% CER inflate NER entity counts by 22% and shift POS distributions measurably, demonstrating concrete error propagation into downstream tasks.
- TrOCR fails entirely on Arabic due to its English-only tokenizer and vision encoder — script compatibility must be verified before investing compute in fine-tuning.
- JSON prefix forcing + token suppression achieves 100% valid JSON output across all 280 eval samples.
